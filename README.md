# dashboard-cocacola-femsa
# 📊 Dashboard RH – Coca-Cola FEMSA

> **Ferramenta:** Power BI  
> **Contexto:** Projeto pessoal desenvolvido para prática e portfólio  
> **Área:** RH — Gestão de Vagas, Ativos e Turnover

## 🧩 O Problema
Simular uma solução de BI para acompanhamento de indicadores de RH de uma grande operação, centralizando métricas de vagas, colaboradores ativos e turnover em um único painel navegável.

## 💡 A Solução
Dashboard com identidade visual personalizada e navegação lateral estruturada entre múltiplas visões:
- **Home** — visão geral dos indicadores
- **Visão Geral** — panorama completo da operação
- **Vagas** — controle de posições abertas
- **Ativos** — monitoramento de colaboradores ativos
- **Turnover** — análise de rotatividade

## 🛠️ Tecnologias
| Ferramenta | Uso |
|---|---|
| Power BI | Dashboard e navegação entre páginas |
| DAX | Métricas e indicadores de RH |
| Power Query (M) | Tratamento e modelagem dos dados |


## 📈 Destaques
- Identidade visual personalizada com a marca Coca-Cola FEMSA
- Navegação lateral entre páginas para melhor experiência do usuário
- Projeto desenvolvido por iniciativa própria para consolidar habilidades em Power BI
